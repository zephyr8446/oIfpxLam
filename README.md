# 项目简介

## 核心功能
- 提供完整的工业零件检测系统源代码
- 包含1500张标注数据集，涵盖14类零件（六角螺丝、双六角柱、T形螺丝、法兰螺母等）
- 预训练好的YOLOv8模型及训练结果
- 支持多种输入源检测：单张图片、图片文件夹、视频文件、本地摄像头
- 实时显示检测结果，包括目标位置、目标总数和置信度
- 支持自定义检测参数：置信度阈值、IOU阈值
- 提供UI界面，可选择显示标签和原图
- 支持批量检测并查看所有结果
- 提供项目运行教程和环境配置文件

## 适用场景
- 工业零件质量检测与分类
- 自动化生产线零件识别
- 仓库库存盘点与分类管理
- 制造业零件计数与统计
- 工业自动化视觉检测系统

## 技术特点
- 基于YOLOv8深度学习框架构建
- 采用Python 3.9开发环境
- 集成OpenCV、PyQt5等计算机视觉库
- 提供图形化用户界面操作
- 支持多格式输入输出
- 模块化设计，便于功能扩展
